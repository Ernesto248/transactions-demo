# Transactions Demo

This repository is a standalone, public, static Next.js demonstration. All records must be synthetic and browser-local. Never add production API routes, database connections, webhooks, credentials, real customer data, or environment variables. Keep the simulator's calculations internally consistent and test them before publishing. Run `pnpm test`, `pnpm typecheck`, and `pnpm build` after changes.
